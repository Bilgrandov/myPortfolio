# My-mind

Dari dulu sejak SD sampai saya kuliah, saya hanya diberi petunjuk oleh orang terdekat saya. Bisa dibilang merekalah yang membuka jalan terus-menerus kepada saya. SD sampai SMK bisa saya lewati bukan karena saya merasa bisa, tapi mungkin karena saya terbiasa melewati hal-hal tersebut dan ada rasa takut jika saya gagal. 

Ada suatu momen ketika saya gagal SNBT. Saya merasa di waktu itu saya harus membuat pilihan saya sendiri, yaitu memilih *gap year*. Pada saat itu adalah momen saya merasa bisa memilih pilihan sendiri dan sudah berkomitmen untuk "balas dendam" di SNBT selanjutnya. 

Hanya saja, pada momen itu ibu saya tidak mau saya untuk *gap year*, mungkin karena takut saya terlihat seperti pengangguran. Lalu, kakak saya memberi info kepada saya untuk ikut ujian mandiri. 

Problemnya, di waktu itu saya benar-benar tidak mengenal apa yang saya hadapi. Saya hanya mengikuti arus dan berhasil terlewati arusnya. Karena saya tidak mengenal lebih dalam tentang kehidupan pada waktu itu, saya melewati kesempatan-kesempatan yang mungkin bisa mengubah hidup saya di masa kuliah. Hal yang paling saya rasa membuat saya susah adalah pilihan saya untuk magang di waktu kuliah. Saya memilih tempat pemerintahan yang mana magangnya tidak sesuai dengan jurusan kuliah saya.

Problemnya sekarang: saya menjadi sosok yang mungkin tidak ingin dilihat oleh ibu saya. Saya sudah lulus kuliah, tapi saya sekarang sudah menganggur nyaris setahun. 

Entah kenapa harus di waktu saya lulus, AI sudah berkembang sejauh ini. Alhasil, *skill entry level* yang sudah saya pelajari di kuliah tidak terpakai. Rasa tertinggal, hutang masa lalu, dan merasa gagal memenuhi ekspektasi selalu menghantui saya ketika melihat teman-teman saya berhasil. Saya juga sangat menyesal tidak mempunyai teman yang bisa diajak *growth up* bersama-sama agar proses *growth up* ini terasa lebih menyenangkan.
